How it works

  1. Your browser turns the password into a SHA-1 hash (a scrambled fingerprint).
  2. Only the first 5 characters of the hash are sent to the Pwned Passwords API.
  3. The API returns every breached has starting with those 5 characters, often hundreds of them.
  4. Your browser checks the list itself, so the API never knows which password you checked.

This technique is called k-anonymity Data from Have I Been Pwned.

Staying safe

Use a passphrase

Three random words are longer, and easier to remember, than a short complex password.

Turn on 2-step verification

Even if a password leaks, a second step stops most attackers getting in.
